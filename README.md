# Kiaf-SEOUL-web-page

Kiaf SEOUL 웹페이지를 참고하여 HTML과 CSS로 구현한 정적 웹페이지입니다.
메인 페이지를 중심으로 About, Organizer, Partners, Visit, Contact, Login, Register, Insights, News 페이지를 구성했습니다.

## 사용 기술

* HTML
* CSS

## 주요 구현 내용

* 상단 고정 헤더 및 메뉴 구성
* 메인 페이지 섹션 구성
* About, Organizer, Partners, Visit, Contact 페이지 구성
* Login, Register 페이지 화면 구성
* Insights, News 목록 페이지 구성
* 이미지와 폰트를 활용한 페이지 스타일링
* 하단 푸터 및 상단 이동 버튼 구성

## 폴더 구조

```text
Kiaf-SEOUL-web-page-main/
├── index.html
├── about.html
├── organizer.html
├── partners.html
├── visit.html
├── contact.html
├── login.html
├── register.html
├── insights.html
├── news.html
├── css/
│   └── mywebstyle.css
├── images/
└── font/
```

## 실행 방법

별도의 서버 실행 없이 브라우저에서 `index.html` 파일을 열면 확인할 수 있습니다.

```text
index.html 실행
```

또는 프로젝트 폴더에서 원하는 HTML 파일을 직접 열어 각 페이지를 확인할 수 있습니다.

## 페이지 구성

| 파일명              | 설명                |
| ---------------- | ----------------- |
| `index.html`     | 메인 페이지            |
| `about.html`     | Kiaf SEOUL 소개 페이지 |
| `organizer.html` | 주최 및 관련 정보 페이지    |
| `partners.html`  | 파트너사 정보 페이지       |
| `visit.html`     | 방문 안내 페이지         |
| `contact.html`   | 연락처 안내 페이지        |
| `login.html`     | 로그인 화면            |
| `register.html`  | 회원가입 화면           |
| `insights.html`  | 인사이트 목록 페이지       |
| `news.html`      | 뉴스 목록 페이지         |

## 참고 사항

* 본 프로젝트는 정적 웹페이지로 구현되었습니다.
* 로그인, 회원가입, 검색 기능은 화면 구성 중심이며 실제 서버 연동은 포함되어 있지 않습니다.
* 이미지와 폰트 파일은 기존 프로젝트 폴더 구조를 유지해야 정상적으로 표시됩니다.
